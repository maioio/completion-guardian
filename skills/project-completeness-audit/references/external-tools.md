# External audit tools (optional)

Examples: Repomix (repo packing), DeepWiki-style repo summaries, doc-drift checkers.

Before using one: read its README and source/permissions; check its license; learn what leaves the machine (never send private or client code to a hosted service without the user's approval); pin a version; run read-only on a copy or with no write flags. Never pipe a download into a shell, never install globally unprompted.

Treat output as a lead list. Confirm each finding against the real project before reporting or acting.
